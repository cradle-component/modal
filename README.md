## Setup
* The code in modal.liquid can be added in the theme code or on a page. 
* The form is built in the forms builder in Cradle CMS.
* On a page and the render template needs to be used is there is a form.
* All the content can be placed inside the `<div>` or anywhere in the `<dialog>` element 

## Requirements
* For full button functionality Alpine JS framework is needed
* Forms are built in Cradle CMS
* Translation support in Cradle CMS admin
